Full Stack Developer
(Java + React Preferred)

Full-time 📍 Remote / Hybrid Java · React · Spring Boot

Role Overview

We are looking for a Full Stack Developer who can build scalable web applications and APIs. The role involves working on both frontend and backend, contributing to client projects in web development and AI-integrated applications.

Key Responsibilities

  • Design and build robust RESTful APIs using Java / Spring Boot
  • Develop responsive, performant frontend interfaces using React
  • Collaborate with designers to implement pixel-perfect UIs
  • Write clean, testable, and well-documented code
  • Participate in code reviews and architectural decisions
  • Integrate third-party APIs, AI services, and cloud platforms
  • Deploy and monitor applications on cloud infrastructure (AWS/GCP)

Tech Stack

Core technologies we work with:

Java Spring Boot React.js REST APIs PostgreSQL MySQL Git Docker AWS / GCP Node.js (bonus)

What We're Looking For

  • 1–4 years of full stack development experience
  • Strong proficiency in Java backend development with Spring Boot
  • Solid React.js experience — hooks, state management, component architecture
  • Experience with relational databases (MySQL / PostgreSQL)
  • Familiarity with Git workflows and CI/CD pipelines
  • Problem-solver mindset with attention to code quality

Bonus Points

  • Experience integrating AI/ML APIs (OpenAI, Anthropic, etc.)
  • Microservices architecture experience
  • Knowledge of TypeScript or Next.js
  • Contributions to open-source projects
